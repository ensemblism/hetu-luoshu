# Visual direction

黑曜石般的黑点、柔白点、深墨空间、少量低饱和关系色。图式是主体；数字和方位在图式周围保持小尺度。没有装饰性古风纹样、背景音乐或密集粒子。

One orthographic camera serves oblique, reading and focused views. Object identity is number + local point index, so the 45 common points survive transitions and Hetu's ten-group fades. Height during transitions is an artistic device.

White/black continue to encode odd/even under all phase lenses. Phase colors accent relations. Generating/completing and yin/yang remain separate categories. PBR lighting and a procedurally generated local room environment provide depth without network textures or live shadows.

Scene draws on demand. Sphere geometry and materials are shared through instancing; ticks are one line-segment batch. DPR is capped at 1.5 on standard quality and 1 on light quality. SVG preserves core semantics when WebGL2 fails.
