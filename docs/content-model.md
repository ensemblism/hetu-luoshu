# Content conventions

Primary diagram convention: ten-number Hetu, nine-number Luoshu. Reading orientation: south above, east left. World X points west; world Z points north.

`src/domain/model.ts` is authoritative for quantities, parity, directions, phase associations and arithmetic relations. 3D, SVG and the static poster consume this data.

Sources were inspected on 2026-10-01–02. Quotations use modern punctuation; omitted passages are marked with ellipses. Text in angle brackets in the Tongshi edition is commentary and must not be attributed to the main author without qualification. Avoid claims about exact prehistoric authorship; attribute interpretation to the named text or scholar.

Arithmetic formulas are calculated from the displayed arrangement. They are presented as observations rather than attributed quotations. Current local dot shapes, heights, materials and trajectories are artistic choices. Contemporary instructional wording is authored by the project and should not be presented as ancient teaching.

The Luoshu five-phase layer combines the displayed numerical positions with the later trigram direction–phase associations; central five is assigned earth by the five-direction convention. It is kept separate from Hetu's generating/completing associations. The source for this layer is a later collected commentary, not a claim that the numeric mapping appears verbatim in the ancient canonical passage.
